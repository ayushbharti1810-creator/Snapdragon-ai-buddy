# Snapdragon AI Buddy - On-Device AI Assistant
Built for Qualcomm Snapdragon 8 Gen 3 | 100% Offline, Private & Fast

## Why?
Normal AI needs internet. This runs 100% on-device using Snapdragon NPU - no data leak, super fast response.

## Features
- Voice + Text Chat
- Offline Translation
- Image Understanding (VLM)
- 100% Private - No cloud

## Tech Stack
- Qualcomm AI Hub / QNN
- ONNX Runtime + Snapdragon NPU
- C language

## How to Run
-gcc main.c -o buddy ./buddy
